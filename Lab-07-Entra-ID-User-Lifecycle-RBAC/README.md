# Lab 7 – Microsoft Entra ID User Lifecycle, RBAC & Session Management

## Project Overview
Performed hands-on Identity and Access Management (IAM) administration in Microsoft Entra ID, including directory role assignment, user lifecycle updates, security group membership, account disabling, and session revocation.

## Technologies Used
- Microsoft Entra ID
- Microsoft Entra Admin Center
- Role-Based Access Control (RBAC)
- Security Groups
- Microsoft Entra Audit Logs
- Session and Refresh Token Management

## Lab Objectives
- Assign an administrative directory role.
- Update user identity attributes.
- Manage security group membership.
- Disable user sign-in.
- Revoke active sign-in sessions.
- Verify administrative actions through audit logs.

## Tasks Completed
1. Assigned the Helpdesk Administrator directory role to the test account Alex Chen.
2. Updated the user's department from Engineering to Security Operations.
3. Changed the job title from Junior Developer to Associate Security Analyst.
4. Added the user to the Sec-Grp-SecurityOps security group.
5. Disabled the test account to block new sign-ins.
6. Revoked the user's sign-in sessions.
7. Reviewed audit logs to verify account and access changes.

## Security Concepts Demonstrated
- Identity and Access Management (IAM)
- Role-Based Access Control (RBAC)
- Identity Lifecycle Management
- Least Privilege
- Security Group Administration
- Account Containment
- Audit Logging and Verification

## Results
Successfully documented directory role assignment, identity attribute updates, security group membership changes, account disabling, and session revocation through Microsoft Entra ID administrative workflows and audit evidence.
