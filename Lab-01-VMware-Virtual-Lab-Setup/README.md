# Lab 1 – VMware Virtual Lab Environment Setup

## Project Overview
Built a virtualized Windows lab environment using VMware Workstation Player to support hands-on Identity and Access Management (IAM), Active Directory, and cybersecurity training.

## Technologies Used
- VMware Workstation Player 17
- Windows 11 Host
- Windows Server 2022 Virtual Machine
- Windows 11 Client Virtual Machine
- VMware NAT Networking (VMnet8)

## Lab Environment
- Host Operating System: Windows 11
- Host RAM: 16 GB (current configuration)
- Virtual Network: VMnet8
- Network Subnet: 192.168.116.0/24
- Domain Controller VM: JMC-DC01

## Objectives
- Establish a virtualized Windows lab environment.
- Configure Windows Server and Windows client virtual machines.
- Configure virtual networking.
- Troubleshoot network connectivity.
- Prepare the infrastructure for Active Directory and IAM labs.

## Tasks Completed
1. Installed and configured VMware Workstation Player.
2. Created Windows Server 2022 and Windows 11 virtual machines.
3. Configured NAT networking using VMnet8.
4. Worked through virtual network configuration and connectivity issues.
5. Prepared the environment for subsequent Active Directory labs.

## Skills Demonstrated
- Virtualization
- Windows Server Administration
- Virtual Networking
- Network Troubleshooting
- IT Infrastructure Setup

## Results
Established a reusable virtual lab environment for practicing Active Directory, identity administration, and cybersecurity tasks.
