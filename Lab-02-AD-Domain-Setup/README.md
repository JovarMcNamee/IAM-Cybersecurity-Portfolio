# Lab 2 – Active Directory Domain Setup & Windows 11 Domain Join

## Project Overview
Built a simulated corporate Active Directory environment using Windows Server 2022 and Windows 11 virtual machines.

## Lab Environment
- Windows Server 2022
- Windows 11
- VMware Workstation Player
- Active Directory Domain Services (AD DS)
- Domain: jmc-local
- Domain Controller: JMC-DC01

## Objectives
- Configure a Windows Server domain controller.
- Establish an Active Directory domain.
- Configure virtual machine networking.
- Join a Windows 11 workstation to the domain.
- Verify domain connectivity and authentication.

## Tasks Performed
1. Configured the Windows Server 2022 virtual machine.
2. Established the jmc-local Active Directory domain.
3. Configured the JMC-DC01 domain controller.
4. Worked with virtual networking and domain connectivity.
5. Configured Windows 11 domain integration.
6. Tested domain authentication and connectivity.

## Security Concepts Demonstrated
- Active Directory Domain Services
- Domain Authentication
- Windows Server Administration
- Virtual Networking
- Identity Infrastructure
