Lab 6 – Microsoft Entra ID MFA

Project Overview
Configured and tested multifactor authentication (MFA) in a Microsoft Entra ID lab environment using a test user account.

Technologies Used
- Microsoft Entra ID
- Microsoft Authenticator
- Microsoft Entra Admin Center
- Sign-in Logs
- Security Defaults

Tasks Completed
- Registered Microsoft Authenticator for a test user.
- Verified available authentication methods.
- Initiated an MFA number-matching challenge.
- Investigated failed and interrupted sign-in attempts.
- Reviewed successful authentication events.
- Confirmed that MFA requirements were satisfied.

Security Concepts Demonstrated
- Identity and Access Management (IAM)
- Multifactor Authentication (MFA)
- Authentication Monitoring
- Identity Security
- Sign-in Troubleshooting

Results
Successfully verified that the test user's sign-in satisfied Microsoft Entra ID's MFA requirement. Reviewed authentication details and confirmed that Security Defaults were applied.
