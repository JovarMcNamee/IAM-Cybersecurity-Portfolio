# Lab 3 – Active Directory HelpDesk Access & Permissions

## Project Overview
Configured and troubleshot Active Directory user access and shared-folder permissions in a Windows Server 2022 lab environment.

## Lab Environment
- Windows Server 2022
- Windows 11
- Active Directory Domain Services
- VMware Workstation Player
- Domain: jmc-local
- Domain Controller: JMC-DC01

## Objectives
- Manage Active Directory user accounts.
- Configure HelpDesk security group access.
- Apply role-based access control (RBAC).
- Troubleshoot authentication and authorization issues.
- Verify network share access.

## Tasks Completed
1. Worked with the David Williams (dwilliams) test account.
2. Configured membership in the GG-IT-HelpDesk security group.
3. Tested access to the JMC-HelpDesk shared folder.
4. Investigated network path and sign-in errors.
5. Troubleshot access-denied errors and adjusted permissions.
6. Verified connectivity after configuration changes.

## Security Concepts Demonstrated
- Identity and Access Management (IAM)
- Role-Based Access Control (RBAC)
- Least Privilege
- Active Directory Administration
- Share and NTFS Permissions
- Authentication and Authorization Troubleshooting

## Results
Troubleshot Active Directory account access, security group membership, and shared-folder permission issues in a simulated enterprise environment.
